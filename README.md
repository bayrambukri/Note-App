
# Note-App

Basit ve modern bir not uygulaması. Notlarınızı oluşturabilir, düzenleyebilir, silebilir ve detaylarını görüntüleyebilirsiniz.

## Özellikler
- Not ekleme, düzenleme ve silme
- Not detaylarını görüntüleme
- Modern ve responsive arayüz
- React + TypeScript + Vite altyapısı


## Proje Yapısı
```
├── public/           # Statik dosyalar
├── src/              # Uygulama kaynak kodu
│   ├── components/   # Bileşenler
│   ├── pages/        # Sayfalar
│   ├── assets/       # Görseller
│   └── ...
├── index.html        # Giriş noktası
├── package.json      # Proje bağımlılıkları
└── ...
```

## Kullanılan Teknolojiler ve Kütüphaneler
- React
- TypeScript
- Vite
- CSS Modules
- react-router-dom
- react-bootstrap
- bootstrap
- react-markdown
- react-select
- uuid
